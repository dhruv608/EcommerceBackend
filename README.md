### 🛠️ **Installation Steps**

#### **1️⃣ CLONE THE REPOSITORY**
```bash
# 🍴 FORK AND CLONE
git clone https://github.com/yourusername/LightStore-Backend.git
cd LightStore-Backend

# 🌟 CHECKOUT THE LATEST VERSION
git checkout main
git pull origin main
```

#### **2️⃣ DATABASE SETUP**
```bash
# 🗄️ SET UP POSTGRESQL (LOCAL)
# Create database:
CREATE DATABASE lightstore;

# OR USE NEON.TECH (CLOUD)
# 1. Sign up at https://neon.tech
# 2. Create new project
# 3. Copy connection string
# 4. Update application.properties
```

#### **3️⃣ CONFIGURE ENVIRONMENT**
```bash
# ⚙️ UPDATE APPLICATION PROPERTIES
# Edit src/main/resources/application.properties
# Update database URL, username, and password
# Configure JWT secret key
# Set CORS allowed origins
```

#### **4️⃣ BUILD AND RUN**
```bash
# 🏃‍♂️ USING MAVEN
mvn clean install
mvn spring-boot:run

# 🐳 OR USING DOCKER
docker build -t lightstore-backend .
docker run -p 8080:8080 lightstore-backend

# ☕ OR RUN FROM IDE
# Run the main application class
```

#### **5️⃣ VERIFY DEPLOYMENT**
```bash
# 🌐 ACCESS THE API
# Local: http://localhost:8080
# Health Check: http://localhost:8080/health
# API Docs: http://localhost:8080/swagger-ui.html

# 🔍 TEST ENDPOINTS
curl -X GET http://localhost:8080/api/products
curl -X POST http://localhost:8080/api/auth/register
```
